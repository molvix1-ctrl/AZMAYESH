# بات پژوهشی سهام ایران

**اجرای مستقل از چت:** [راهنمای ساده میزبانی دائمی](DEPLOY_FA.md).
مسیر رایگان: [ویندوز](WINDOWS_FA.md) یا [گوشی اندرویدی](ANDROID_FA.md).
گوشی/کامپیوتر باید روشن و آنلاین بماند. IP ثابت لازم نیست؛ دسترسی به همه IPها تضمین نمی‌شود.
پیام **تحلیل** برای ترکیب بنیادی و تکنیکال و پیام **قوانین** برای توضیح روش است.
قواعد دائمی در [RULES_FA.md](RULES_FA.md) و کد ذخیره شده‌اند؛ نیازی به هوش مصنوعی یا این چت ندارند.
تحلیل ترکیبی به داده واقعی با قرارداد `fundamentals.example.json` نیاز دارد؛
تأمین خودکار این ارقام هنوز کامل نشده است. بدون داده بنیادی، پیشنهاد ترکیبی ساخته نمی‌شود.

نسخهٔ اولیهٔ بات فارسی تلگرام برای غربال معاملات روزانه با روند پنج جلسهٔ اخیر.
این مخزن تازه ایجاد شده است. اتصال زندهٔ منابع و تلگرام هنوز تأیید نشده؛
آزمون‌های خودکار با پاسخ‌های ساختگی اجرا می‌شوند. آدرس‌های بورسیک و تیندکس مشخص است؛
اتصال دادهٔ آن‌ها تا بررسی API و شرایط دسترسی پیاده‌سازی نشده است.

## اجرا

Python 3.11 یا جدیدتر و بسته `tzdata` در `requirements.txt` لازم است.

```bash
cd /workspace/AZMAYESH
python3 -m pip install -r requirements.txt
python3 -m unittest -v
python3 bot.py --demo
python3 bot.py --scan  # نیازمند دسترسی اینترنت به TSETMC
```

برای تلگرام، با BotFather بات بسازید. توکن را فقط در متغیر محیطی امن
`TELEGRAM_BOT_TOKEN` قرار دهید؛ توکن را در چت، کد، گزارش یا Git ننویسید.
برنامه فایل `.env` را خودکار بارگذاری نمی‌کند.
`TELEGRAM_CHAT_ID` برای نسخه شخصی الزامی است؛ بات فقط همان چت را پاسخ می‌دهد.
حالت عمومی با `BOT_PUBLIC=true` فعال می‌شود و برای این کاربر انتخاب نشده است.
راه‌اندازهای محلی از `configure.py` و `launcher.py` برای ذخیره خصوصی و بارگذاری تنظیمات استفاده می‌کنند.

```bash
python3 bot.py
```

این فرمان یک پردازش long polling را در پیش‌زمینه اجرا می‌کند. فقط یک نمونه برای
هر توکن اجرا شود؛ webhook قبلی باید پیش از استفاده از polling حذف شده باشد.
پردازش برای پاسخ‌گویی باید روشن بماند؛ سفارش معاملاتی ثبت نمی‌کند و پیام زمان‌بندی‌شده ندارد.
وضعیت دریافت پیام‌ها در `.state/offset` ذخیره می‌شود. در صورت قطع پس از ارسال و پیش از
ثبت offset ممکن است یک پاسخ تکرار شود. خطاها توکن را چاپ نمی‌کنند.

دستورها: `/start`، `/help`، `/scan`، `/high`، `/low`، `/codal فولاد`، `/status`، `/sources`.

## منابع و محدودیت دسترسی

* TSETMC: `cdn.tsetmc.com`؛ مسیرهای `ClosingPrice/GetMarketWatch` و
  `ClosingPrice/GetClosingPriceDailyList/{insCode}/0`؛ قرارداد پاسخ در `bot.py`.
  این مسیرها ممکن است تغییر کنند؛ تطبیق با پاسخ واقعی هنوز لازم است.
* کدال: `search.codal.ir/api/search/v2/q`؛ فقط عنوان، زمان و لینک اطلاعیه‌های نماد.
  محتوای مالی، اهمیت اطلاعیه و اثر احتمالی بر قیمت تحلیل نمی‌شود.
  لینک گزارش‌ها روی `www.codal.ir` است.
* تلگرام: `api.telegram.org`؛ توکن به صورت استاندارد Bot API در مسیر HTTPS استفاده می‌شود.
  توکن باید واقعاً در پردازش قابل استفاده باشد؛ placeholder پراکسی را بدون پشتیبانی صریح
  جایگزینی در مسیر URL، توکن معتبر فرض نکنید.
* بورسیک `https://bourseek.ir/` و تیندکس `https://tindex.app/`: آدرس‌ها توسط کاربر
  تأیید شده‌اند؛ CONNECT هر دو در محیط فعلی 403 می‌دهد. پس از فعال‌شدن دسترسی،
  API یا روش دریافت مجاز باید بررسی و سپس پیاده‌سازی و آزمون شود.

در محیط فعلی درخواست CONNECT به هر چهار منبع با 403 پراکسی مسدود شد.
اجازهٔ دامنه‌ها باید از تنظیمات محیط اعمال شود؛ ذخیرهٔ پیش‌نویس آن را در ماشین فعال نمی‌کند.
پس از اعمال، ابتدا `--scan` و `/codal` و سپس یک تبادل واقعی تلگرام را بررسی کنید.
هیچ دسترسی، اشتراک یا مجوز خزیدن خودکار مفروض نیست؛ در صورت نیاز از API مجاز استفاده کنید.

## روش غربال اولیه

دو گروه غیرهمپوشان، هرکدام حداکثر پنج نماد، از میان حداکثر ۴۰ نماد با بیشترین
ارزش معاملات انتخاب می‌شوند. پیش‌فرض آخرین جلسه موجود، با تاریخ روشن و حداکثر هفت روز
قبل است؛ برای بررسی جلسه بعد و با هشدار غیرزنده‌بودن قیمت‌ها. در `REPORT_MODE=live`
فقط داده حداکثر ده دقیقه قبل پذیرفته می‌شود. دامنه تمام بازار نیست.
برای هر نماد ۲۱ جلسهٔ کامل پیش از تاریخ عکس بازار لازم است؛ همان جلسه در سابقه وارد نمی‌شود.
حداقل ارزش معاملات روز و میانگین ۲۰جلسه‌ای هر دو ۱۰ میلیارد ریال است.
قیمت خریدوفروش دوطرفه و حجم مثبت، فاصلهٔ حداکثر یک درصد، روند پنج‌جلسه‌ای مثبت
و قیمت بالاتر از میانگین ۲۰جلسه لازم است. نمادهای صف بدون عرضه یا تقاضای معتبر حذف می‌شوند.

نوسان انحراف معیار بازده سادهٔ ۲۰ جلسه است: بیشتر از ۲٪ برای گروه پرریسک؛
حداکثر ۲٪ همراه فاصلهٔ خریدوفروش حداکثر نیم درصد برای گروه با ریسک پایین‌تر.
امتیاز = `100*momentum + min(volume_ratio,3) + log10(avg_value/1e9) - 100*spread`؛
در گروه آرام‌تر `100*volatility` نیز کم می‌شود.
این آستانه‌ها فرضیهٔ پژوهشی هستند، با دادهٔ بازار بهینه یا اعتبارسنجی نشده‌اند.

قیمت تاریخی تعدیل‌نشده است؛ بازده تک‌جلسه‌ای با قدر مطلق بیش از ۱۵٪ حذف می‌شود.
این فیلتر جایگزین دادهٔ تعدیل‌شده و تشخیص افزایش سرمایه، سود نقدی یا بازگشایی نیست.
نسبت حجم جاری به میانگین روزهای کامل در ابتدای بازار سوگیری دارد.
توقف نماد، وضعیت رسمی مجازبودن معامله و محدودیت دامنه قیمت جداگانه تأیید نشده‌اند؛
قبل از معامله باید بررسی شوند. داده بیش از هفت روز در حالت آخرین جلسه هم پذیرفته نمی‌شود.

## سنجش سود هفتگی

این نسخه سود هفتگی، حد ورود، هدف یا حد ضرر پیشنهادی تولید نمی‌کند.
برای ادعای «بیشترین سود» یا کارایی روزانه، لازم است دادهٔ تاریخی تعدیل‌شده و
دادهٔ درون‌روزی دریافت شود و بک‌تست خارج از نمونه با کارمزد، لغزش، محدودیت صف،
توقف، سوگیری بقا و نبود نگاه به آینده اجرا شود. معیارهای لازم شامل بازده خالص،
افت سرمایه و زیان معاملات است. بدون این مرحله، خروجی فقط فهرست بررسی انسانی است.
گروه کم‌نوسان تضمین سود کم یا ریسک پایین مطلق نیست.

## توسعه و آزمون

`test_bot.py` تازگی داده، گروه‌بندی، نقدشوندگی، جهش تعدیل، دادهٔ خراب، خرابی منبع،
فیلتر خروجی، دستور تلگرام و قالب کدال را با fixture بررسی می‌کند.
`--demo` فقط نمادهای ساختگی با برچسب روشن چاپ می‌کند و به بات زنده تزریق نمی‌شود.
موفقیت این آزمون‌ها اثبات اتصال واقعی API یا سودآوری راهبرد نیست.
